# FinanceManager v0.1.0

## Resumen

Primera versión del núcleo contable de FinanceManager, una aplicación de finanzas personales que usa Claude.ai como interfaz mediante MCP remoto.

## Novedades

- Contabilidad de partida doble, cuentas, categorías, ingresos, gastos y transferencias multimoneda.
- Importación por lotes, conciliación, etiquetas, campos personalizados y deshacer operaciones.
- Préstamos hechos y recibidos con interés simple y abonos que cubren primero el interés pendiente.
- Herramientas MCP en español, OAuth 2.1 con TOTP, consulta SQL de solo lectura y copias cifradas.
- Guías para despliegue, recuperación y mantenimiento.

La migración de préstamos reutiliza una categoría `Intereses` existente bajo Ingresos o Gastos sin distinguir mayúsculas ni tildes; la convierte en categoría de sistema y la normaliza al nombre `Intereses`.

## Requisitos de despliegue

- Node.js 22 y MariaDB 10.6.
- cPanel con Application Manager y Passenger, una base principal y una base de lectura con su usuario de permisos limitados.
- Configuración de OAuth, TOTP, HTTPS y variables de entorno según la [guía de despliegue](../operacion/despliegue.md).

## Limitaciones conocidas

- El dashboard aún no está incluido; está previsto para el incremento 2.
- No se comprobaron en un VPS real la instalación de GPG/rclone, permisos y publicación en cPanel, cron y correo, Drive, OAuth en Claude.ai ni la restauración en VPS. La integración de Drive local utilizó un doble. Claude.ai web y móvil también quedan pendientes de la prueba P3.
- MariaDB 10.6 ya no recibe soporte regular; se mantiene aquí por compatibilidad con el entorno objetivo.

## Actualización

Haz una copia y sigue el procedimiento de despliegue y migración de la [guía de operación](../operacion/despliegue.md). Conserva la copia previa hasta validar el estado de la aplicación y la base; consulta la [guía de recuperación](../operacion/recuperacion.md) si necesitas revertir.
